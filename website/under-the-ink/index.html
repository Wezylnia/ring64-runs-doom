under the ink

why ink

i wanted the slow pull of a lava lamp, with edges that spread like ink in water. mostly i wanted to pass through the red and take a little of it with me.

ink in code

i wanted wet ink to work like the demoscene pieces i’d been trying. i feed my pointer position to a small c program that moves the pigment. the renderer gives it color and draws it on the canvas.

why ring64

i compile the c program to x86-64 because i want ring64 to run it. the browser needs an emulator for those instructions. ring64 translates them into webassembly as the program runs. i could compile the same c straight to webassembly, too.
