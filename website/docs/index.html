quickstart

run two x86-64 instructions that add 40 and 2.

npm install ring64

save add.ts and run node add.ts. it prints 42n from rax.

view add.ts
add.ts

if node reports an unknown .ts extension, use node --experimental-strip-types add.ts.

run in a browser

bundle the same add.ts and put ring64.wasm beside the bundle.

terminal 
npx esbuild add.ts --bundle --format=esm \
  --outfile=public/add.js
cp node_modules/ring64/ring64.wasm public/

add this to public/index.html.

<script type="module" src="./add.js"></script>

serve public/ over http and open the page. 42n appears in the browser console.

run a binary

pass a Uint8Array of raw instruction bytes as code.bytes and choose a load address in code.base. if you have an elf or pe file, load its sections and set up the guest state in your app.

example · load a c function

use clang and llvm-objcopy to extract the function's instruction bytes.

add.c
terminal 
clang --target=x86_64-unknown-none-elf -O2 -ffreestanding \
  -fno-stack-protector -fomit-frame-pointer -mno-red-zone \
  -c add.c -o add.o
llvm-objcopy -O binary --only-section=.text add.o add.bin

add-c.ts passes arguments in rdi and rsi and places a return address on the guest stack. follow the browser steps with this file and put add.bin beside the bundle. it prints 42n.

parallel

use createMachine from ring64/parallel to run vcpus on separate workers with shared guest memory.

parallel.ts runs the same addition on two vcpus with different inputs. run node parallel.ts to get [42n, 12n]. see machine options and browser requirements.
